## Stage B — Exercise 1: Managing a Reading List

Difficulty: Beginner–Intermediate\
Concepts: Arrays, searching, indexes, conditional statements and Array manipulation.

### Problem

You're developing a simple application that manages a reading list.

The application initially contains four books:

| Index | Book       |
| ----- | ---------- |
| 0     | Dune       |
| 1     | 1984       |
| 2     | Dune       |
| 3     | Clean Code |

Your task is to write a JavaScript program that removes a book from the reading list.

### Requirements

1. Create an Array containing the four books.
2. Create a function that receives a book title
3. Check whether that book exists in the Array.
4. If it exists, remove only its first occurrence.
5. If it doesn't exist, leave the Array unchanged.
6. Display whether the book was found and show the updated Array.

### Test cases

| Book to remove | Expected behaviour                           |
| -------------- | -------------------------------------------- |
| `"Dune"`       | Remove the first Dune, preserving the second |
| `"The Hobbit"` | No removal; book doesn't exist               |
| `"1984"`       | Remove 1984                                  |

Run these tests sequentially, using the same Array.

### Restrictions

- Write the implementation yourself, starting from an empty JavaScript file.
- You may consult documentation and your study files.
- Don't use AI-generated solutions.
- You decide which Array methods are appropriate.
