# 📌 javascript & node.js study

this repository contains all the code i'm developing during my autonomous **javascript** and **node.js** learning journey. i'm practicing fundamental concepts, solving coding challenges, and exploring different data structures and programming paradigms.

## 📂 content

here you'll find a variety of code organized by topics:

### javascript fundamentals

✅ **data types:** strings, numbers, booleans, undefined, null, symbols  
✅ **reference types:** objects and their manipulation  
✅ **scopes:** global, function, and block scope (var, let, const)  
✅ **hoisting:** understanding variable and function hoisting behavior  
✅ **prototypes & inheritance:** prototypal inheritance and class-based inheritance

### data structures

✅ **arrays:** manipulation, iteration, and array methods  
✅ **objects:** creation, modification, and deletion of properties  
✅ **sets:** unique value collections  
✅ **maps:** key-value pair collections  
✅ **weakmap & weakset:** garbage-collectible collections

### node.js

✅ **global keywords:** understanding node.js global objects  
✅ **assertions:** testing with assert module  
✅ **data structures in node:** map, set, weakmap, weakset implementations

### coding challenges

✅ **leetcode solutions:** problem-solving practice

- two sum
- add two numbers (linked lists)

### additional topics

✅ **json:** parsing and working with json data  
✅ **html integration:** connecting javascript with html
